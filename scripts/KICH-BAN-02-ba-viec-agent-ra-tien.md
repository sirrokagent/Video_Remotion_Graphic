### [0:00 – 0:15] HOOK

Video trước tôi chỉ các sếp Agent nằm ở đâu. //
Bật Codex trong ChatGPT, bật Claude Code trên máy tính. //
Rồi nhiều sếp nhắn lại cùng một câu: bật được rồi, giờ làm gì? //
Hôm nay tôi trả lời đúng câu đó. //
Ba việc cụ thể. Giao cho Agent. Ra tiền ngay trong tuần này. //
Không lý thuyết, không công cụ mới, không phải học thêm gì.

### [0:15 – 0:36] NÓI THẲNG TRƯỚC KHI VÀO

Nhưng trước hết, một câu thật lòng, nghe hơi phũ. //
Agent không tự kiếm tiền cho các sếp. //
Nó không tạo ra khách hàng, không tạo ra nhu cầu, không tạo ra thị trường. //
Nó chỉ nhân cái các sếp đang làm lên nhiều lần. //
Ai chưa có việc gì ra tiền, thì nhân với bao nhiêu cũng vẫn bằng không. //
Còn ai đã có một việc chạy được rồi, dù nhỏ — ba phần sau đây là đòn bẩy thật. //
Tôi nói trước để các sếp khỏi mất thời gian.

### [0:36 – 1:07] VIỆC 1 — BÁN LẠI CHÍNH THỜI GIAN VỪA TIẾT KIỆM

Việc thứ nhất. //
Chọn đúng một đầu việc các sếp làm đi làm lại mỗi tuần. //
Dựng báo giá cho khách. Dọn dữ liệu đơn hàng. Soạn hợp đồng theo mẫu có sẵn. //
Chọn việc nào tốn thời gian nhất mà lại ít phải suy nghĩ nhất. //
Giao nguyên khối đó cho Agent. //
Lưu ý chỗ này: không phải hỏi nó cách làm — mà bảo nó làm. //
Đưa file thật, thư mục thật, rồi ngồi xem nó thao tác. //
Việc bốn tiếng rút còn hai mươi phút. //
Và đây mới là phần quan trọng. //
Ba tiếng rưỡi vừa dư ra đó, đem bán. //
Nhận thêm khách. Nhận thêm đơn. Gọi cho người mà tháng trước các sếp không có thời gian gọi. //
Tiền không đến từ con Agent. Tiền đến từ chỗ trống nó vừa tạo ra.

### [1:07 – 1:33] VIỆC 2 — TỰ LÀM THỨ TRƯỚC ĐÂY PHẢI ĐI THUÊ

Việc thứ hai. //
Mở lại hoá đơn ba tháng gần nhất. //
Khoản nào các sếp đang trả tiền cho người khác làm hộ? //
Một trang bán hàng. Một con bot trả tin nhắn khách. Một file tự động gom số liệu cuối tháng. //
Mở Claude Code hoặc Codex, mô tả bằng tiếng Việt, để nó làm. //
Cái trước đây báo giá mười lăm triệu và chờ ba tuần — giờ là một buổi chiều. //
Không biết code vẫn làm được. Tôi nói thật là vậy. //
Nhưng phải mô tả cho rõ. Rõ đến mức người lạ đọc vào cũng làm đúng. //
Đó mới là kỹ năng thật, và là thứ duy nhất các sếp cần luyện.

### [1:33 – 1:54] VIỆC 3 — BÁN LẠI QUY TRÌNH CHO NGƯỜI CÙNG NGÀNH

Việc thứ ba, và là việc ra tiền nhanh nhất. //
Cái quy trình các sếp vừa dựng cho mình — bán nó cho người cùng ngành. //
Chủ shop nào cũng cần dọn đơn. Phòng khám nào cũng cần nhắc lịch. Trung tâm nào cũng cần chấm bài. //
Các sếp đã chạy thật, đã vấp, đã biết chỗ nào nó hỏng và sửa thế nào. //
Đó mới là thứ người ta trả tiền. //
Không phải con Agent — ai cũng tải được. //
Mà là việc các sếp đã đi trước và vấp trước.

### [1:54 – 2:08] GIỚI HẠN + CHỐT

Nói nốt phần không ai nói với các sếp. //
Agent làm sai. Nó làm sai nhanh, và làm sai rất tự tin. //
Việc nào đụng tiền, đụng khách, đụng pháp lý — phải có người kiểm trước khi gửi đi. //
Chọn một việc. Làm trong tuần này. Xong quay lại kể tôi nghe. //
Đừng chỉ đứng nhìn. Hãy tham gia cuộc chơi.
